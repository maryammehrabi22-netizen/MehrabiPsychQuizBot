# راهنمای راه‌اندازی بات آزمون‌ساز روان‌پزشکی

## چی داری؟
- `bot.js` — کد اصلی بات
- `data/` — بانک‌های سوال (فایل‌های json). هر فایل = یک بانک جدا در منو
- `convert_html_to_json.js` — ابزار تبدیل فایل‌های HTML قبلی‌ات به json برای بات

## قابلیت‌ها
- منوی انتخاب بانک سوال (`/start` یا `/menu`)
- نمایش سؤال با گزینه‌های الف/ب/ج/د + قفل‌شدن بعد از پاسخ
- نمایش توضیح، دام تستی و قاعده کلیدی بعد از پاسخ (اگر در داده موجود باشد)
- دکمه‌های بعدی/قبلی، پرچم برای مرور، رفتن به شماره سؤال خاص
- پایان آزمون → خلاصه نمره و لیست سؤالات پرچم‌گذاری‌شده

## مرحله ۱ — اضافه‌کردن بانک سوال از فایل‌های HTML قبلی‌ات

اگر فایل مشابه ساختار `makeQ(theme, stem, options, correct, explanation, quote, trap, rule)` داری:

```bash
node convert_html_to_json.js path/to/quiz.html data/اسم-بانک.json
```

خروجی رو داخل پوشه `data/` می‌ذاره و بات خودکار می‌بینتش (نام فایل = اسمی که در منو نشون داده می‌شه).

اگر ساختار فایل فرق داره، فایلش رو برام بفرست تا converter رو تطبیق بدم.

## مرحله ۲ — گرفتن توکن از BotFather
(همون مرحله‌ای که قبلاً انجام دادی — توکن رو یه جای امن نگه دار)

## مرحله ۳ — بالا بردن روی Render (رایگان)

1. برو [render.com](https://render.com) و با گیت‌هاب یا ایمیل ثبت‌نام کن
2. یه ریپازیتوری گیت‌هاب بساز و کل این پوشه (`psych-quiz-bot`) رو توش آپلود کن
   - ساده‌ترین راه: از سایت github.com یه ریپو جدید بساز، بعد فایل‌ها رو با دکمه "Upload files" درگ-اند-دراپ کن
3. توی Render: **New +** → **Web Service** → ریپازیتوری‌ات رو انتخاب کن
4. تنظیمات:
   - **Build Command:** `npm install`
   - **Start Command:** `node bot.js`
5. برو بخش **Environment** و یک متغیر اضافه کن:
   - Key: `BOT_TOKEN`
   - Value: همون توکنی که از BotFather گرفتی
6. **Create Web Service** رو بزن — چند دقیقه طول می‌کشه تا دیپلوی بشه
7. وقتی لاگ نوشت `بات با موفقیت روشن شد.` یعنی بات آنلاینه

## مرحله ۴ — تست
تو تلگرام برو سراغ بات خودت (همون یوزرنیمی که ساختی)، بزن `/start` و باید منوی بانک‌های سوال رو ببینی.

## نکته برای کانال
این بات به‌صورت پیام خصوصی با هر کاربر کار می‌کنه (مثل نمونه‌ای که فرستادی). اگه می‌خوای اعضای کانالت ازش استفاده کنن، لینک بات رو (`t.me/یوزرنیم_بات`) توی کانال پست کن تا هرکی بخواد باهاش شروع کنه.

## اضافه‌کردن بانک‌های بیشتر بعداً
هر فایل json جدید که بریزی توی `data/` (با همون ساختار)، خودکار توی منو ظاهر می‌شه — نیازی به تغییر کد نیست.
